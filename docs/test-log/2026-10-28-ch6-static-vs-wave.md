# 2026-10-28 チュートリアル 6 章の記録: 静かなときと手を振ったとき（Linux 実機）

## 条件

- 機材: M5Stack Basic 2 台（CH9102）。T1（送信機・モバイルバッテリー給電）・R1（受信機・USB で PC へ）。
  ファームは `v0.1.0-rc.1` の .bin（版 `1028-f107684`。`2026-10-28-release-rc1-flash.md`）
- 置き方: T1 と R1 を 190 cm 離して向かい合わせ、間に物なし。PC は R1 から約 20 cm・2 台を結ぶ線の外。ch11
- 部屋には利用者 1 人と犬 1 匹（犬は動きを止めていない）。各 30 秒、`csikit record --start-delay 10`
- 解析: `examples/tutorial/compare_motion.py`（形 = 振幅 ÷ パケットの平均、の 1 秒ごとの標準偏差を 56 本で平均）
- 同じ日の 11:48 に同じ距離で static を 1 回取ったが、その後に置き方を崩したので、置き直して static から取り直した

## 記録の品質

| 記録 | 受信レート | 連番の欠け | CRC 不良 |
|---|---|---|---|
| static | 96.5 Hz | 106 | 1 |
| wave（手先で小さく） | 99.4 Hz | 17 | 1 |
| wave（腕全体で大きく） | 99.9 Hz | 2 | 1 |

static だけ欠けが多かった（約 3.5 %）。原因は調べていない。

## 動きの大きさ（1 秒ごと・30 秒分）

| 項目 | 設計値 | 実測値 | 差 | 測り方 |
|---|---|---|---|---|
| static 平均（最小〜最大） | — | 0.021（0.019〜0.031） | — | compare_motion |
| wave 大きく 平均（最小〜最大） | static より大きい | 0.034（0.028〜0.048） | static の 1.6 倍 | compare_motion |
| wave 小さく 平均（最小〜最大） | static より大きい | 0.028（0.023〜0.051） | static の 1.3 倍 | compare_motion |
| 練習用データ（参考） | — | wave は static の 9.6 倍 | 実機は 1/6 程度 | `compare_motion.py --demo` |
| 11:48 の static（置き直す前） | — | 0.021（0.017〜0.057） | 最大が今回の約 2 倍 | compare_motion |

- 小さく振ったときは 3 秒目・12 秒目に山がある他は static に近かった。大きく振ると、30 秒のほとんどで static と分かれた
- static の 20 秒目以降に小さな山（最大 0.031）。記録中、2 台から離れた所で飼い犬が動いていた（記録の後に利用者から聞いた。山との時刻の対応は確かめていない）

## 次にどうするか

- 6 章の手順を「腕全体で大きく振る」に直した。4 章・6 章に図と数値を足した
- 差の大きさは 1 回の結果。置き方・距離（1〜3 m）・振り方を変えて何回か取ると、6 章の 🌳 の「ばらつき」の見本になる（後回し）
