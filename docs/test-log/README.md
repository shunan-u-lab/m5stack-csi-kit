# 実機試験の記録

1 回の試験につき 1 ファイル。名前は `YYYY-MM-DD-<何を試したか>.md`。
過去の記録は書き換えない（設計の前提が実物でどうだったかを残すため）。

## 書くこと

1. **日付**
2. **条件** — 機材（型番）・材料（種類・厚さ）・設定（出力・速度・ファームウェアの版など）
3. **設計値・実測値・差** — 下の表。数値には必ず単位を付ける
4. **次にどうするか** — 設計を直すか、そのままでよいか

| 項目 | 設計値 | 実測値 | 差 | 測り方 |
|---|---|---|---|---|
| （例）取付穴の間隔 | 50.0 mm | 49.8 mm | −0.2 mm | ノギス |
