# チュートリアル — はじめての Wi-Fi CSI

ゼミに入って、**マイコンも、CSI も、パソコンでのプログラミングも初めて**という人のための道案内です。
スマホは使ったことがある、という所から始めて、最後はこのキットの数式とプログラムの中身を読めるところまで進みます。

> 慣れている人は、手順だけをまとめた [README](../../README.md) を見れば足ります。

## 読み方: 各章は 3 段になっています

| 段 | 中身 | 読む人 |
|---|---|---|
| 🌱 **ファーストタッチ** | スマホで経験したことに結びつけたたとえ | 全員。まずここだけでよい |
| 🌿 **しくみ** | 何が起きているかを、言葉と図で | キットを使い始めたら |
| 🌳 **もう一段** | 数式と、それを計算しているこのリポジトリのコード | 研究で使う・自分で変えるとき |

最初は 🌱 だけを読んで先へ進み、手を動かしてから戻って 🌿・🌳 を読む、という読み方を勧めます。
**たとえは入口で、正確な説明の代わりではありません。** 各たとえの後に、正確な言い方と、たとえが当てはまらない所を書いています。

## 先に知っておいてほしいこと

- **CSI は、壁の向こうの人の動きも映します。** 自分以外の人がいる場所で測るときは、必ず相手に伝え、同意をもらってください。
  人を対象にした実験は、大学の研究倫理の手続き（倫理審査など）に従います（[1 章の最後](01_what_is_csi.md#1-6-倫理--測ってよいもの測ってはいけないもの)）

- 分からない言葉は [7 章の用語集](07_troubleshooting_glossary.md#用語集) にあります。まずは [最初に覚える 10 語](07_troubleshooting_glossary.md#最初に覚える-10-語) だけで始められます

## 一人で読む・AI と一緒に読む

どの読み方でも、進める章と打つ命令は同じです。自分に合うものを選んでください。途中で変えてもかまいません。

| 読み方 | 使うもの | このチュートリアルの使い方 |
|---|---|---|
| 一人で読む | このチュートリアルとターミナルだけ | 各手順に**期待する画面の見本**があります。自分の画面と見比べながら進みます。章末の「確かめよう」には**答え**があります（開く前に一度考える） |
| チャット型の AI と読む | ChatGPT・Claude・Gemini など（ブラウザやアプリで、貼って聞く） | 章末の「AI に聞いてみよう」に**聞き方の例**があります。分からない言葉・エラー・図の読み方を聞きます |
| コマンドライン AI と動かす | Claude Code・Codex・Gemini CLI など（このフォルダの中で起動し、命令を実行できる） | 「AI に聞いてみよう」の「コマンドライン AI なら」に**頼み方の例**があります。AI はこのフォルダの `AGENTS.md` を読み、説明しながら進めるよう指示されています |

**AI は近道ではなく、説明役にします。** 「全部やって」と頼むと、AI が先に進めてしまい、仕組みが自分に残りません。

- 頼み方は「一緒にやって、説明して」の形にする。例: 「`uv run csikit doctor` を実行して。実行する前に何をするか教えて、終わったら、どのファイルのどの関数がその表示を出したか教えて」
- 各章の 🌳 の「手を動かして確かめる」の命令は、**自分で打つ**。AI には、結果の読み方とコードの場所を聞く
- 書き込み（`csikit flash`）・組を消す（`csikit unpair`）・SD のファイルを消す命令は、AI が実行する前に「いいですか？」と聞いてきます。何が起きるかが分かってから答える
- 答えをそのまま信じず、**「なぜそうなるの？」「どこで確かめられる？」と続けて聞く**
- エラーは**全部**コピーして見せる（一部だけだと的外れな答えになりやすい）
- 記録のファイルや、周りの Wi-Fi の名前（SSID）を含む画面は、AI に貼る前に中身を考える（個人に関わる情報が入りうる）
