# m5stack-csi-kit — 要件

（2026-10-27 作成。プランで決めた範囲をここに書く）

## 何を作るか

他の大学で Wi-Fi CSI を研究する学生（ゼミに入ったばかりで、マイコン・CSI・プログラミングが初めての人を含む。ADR 0007）が、研究室や自宅の PC（Linux・Windows・Mac）で、M5Stack Basic 2 台から CSI を記録するためのキット。
詳細は `docs/plans/2026-10-27-kit-extraction.md`。

## 必要な性能

- 受信レート 約 100 Hz（10 ms 間隔）、欠けを連番で数えられること
- PC に USB（921600 bps）で流す記録と、PC なしで SD カードへ記録する方法の両方

## 今回の範囲

### 作る

- M5Stack Basic 用の送信機・受信機のファーム（ビルド済み `.bin` も配る）
- PC 側: doctor・flash・monitor・record と、解析のサンプル 1 本
- 日本語と英語の手順書、CI（3 OS）

### 作らない

- 本格的な解析（呼吸・在室推定・行動認識など）
- M5Stack Basic 以外の機種への対応
- 利用者へのサポート

## 使う場所・電源

屋内。USB 給電（5 V）。PC なしの記録では USB 電源で一晩程度

## 扱うデータ

人や場所に結びつくデータを扱うかを、**データが入ってくる前に**決める。

- [ ] 実名・連絡先
- [ ] 設置先・顧客の情報（住所・現場の写真・設置台帳）
- [ ] 個人に結びつくデータ（位置・カメラ・在室・利用者名）
- [ ] NDA を結んだ相手の資料

**判断（2026-10-27）: どれにも当てはまらない。** キットにはコードと、中立な条件で取り直したサンプル（無人・手を振る。BSSID・SSID は伏せる）だけを置く。
利用者が取った記録は `data/` に置き、git に入れない。

1 つでも当てはまるデータは、このリポ（公開する）に置かない。
